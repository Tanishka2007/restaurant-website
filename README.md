# 🌸 Bloom & Butter Café — Artisanal Bakery & Restaurant Website

A responsive, pastel-aesthetic website for an artisanal café, bakery, and brunch kitchen. Built using semantic HTML5, modern CSS3 (Flexbox & CSS Grid), and lightweight vanilla JavaScript.

---

## ✨ Features
- **Pastel Aesthetic Design**: Warm cream (`#FAF7F2`), rose blush (`#FDE2E4`), apricot peach (`#FFDFD3`), sage matcha (`#DCE8E1`), and soft butter yellow (`#FFF1CC`).
- **Dark / Light Mode**: One-click toggle between Soft Cream Day mode and Velvet Espresso Night mode (persisted with `localStorage`).
- **Interactive Menu Filter**: Dynamic filtering across categories (*All Items*, *Artisan Bakery*, *All-Day Brunch*, *Specialty Drinks*, *Desserts*).
- **Curated Menu in Rupees (₹)**: 9 signature dishes with high-resolution food photography, calorie counts, and dietary badges.
- **Specials & Combos**: Weekly highlighted deals with active time slots.
- **Table Reservation Form**: Client-side validated booking form with instant confirmation feedback.
- **Atmosphere Gallery & Testimonials**: Showcase of interior spaces, reviews, star ratings, and community love.
- **Opening Hours & Contact Details**: Formatted schedule and district contact details.
- **Responsive Layout**: Designed for mobile, tablet, and desktop viewports.

---

## 🚀 Quick Start
Simply open `index.html` in any web browser, or serve it with Python:

```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080`.
